# Test-only toolchain, pinned so a tool release cannot turn CI red on an
# unchanged commit (same reason as requirements-dev.txt).
#
# pytest, pytest-asyncio and httpx2 are NOT here: they are already pinned in
# backend/requirements.txt, which tests.yml installs first. Duplicating a
# pin in two files is how the two drift.
#
# coverage, pytest-cov and pytest-xdist are NOT here either: test-ratchet's
# `run` installs its own pinned copies in every cell it runs.

# pyyaml parses .github/workflows/*.yml for the workflow-shape tests and
# lives in requirements-pyyaml.txt since the Python 3.15 move: its --hash
# turns pip's hash-checking on for every requirement in the same
# invocation, so it installs as its own pip command (see that file's
# header for the install shape).
