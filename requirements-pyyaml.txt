# PyYAML parses .github/workflows/*.yml for the workflow-shape tests
# (issue #126). It ships a cp314 wheel but no cp315 one yet (upstream
# yaml/pyyaml#981 and #994 are open), so the hashed command below runs
# FIRST on a fresh environment, before the backend/requirements.txt and
# requirements-test.txt install, and pip builds the pinned sdist on
# every interpreter — including 3.14, where --no-binary=PyYAML
# deliberately overrides the existing cp314 wheel. The sdist hash pins
# that build. A --hash switches pip's hash-checking on for EVERY
# requirement in the same invocation (verified on pip 26.2.1: one hashed
# line turns on --require-hashes for the whole install command), so the
# file installs as its own pip command:
#
#   pip install --require-hashes --only-binary=:all: --no-binary=PyYAML \
#     -r requirements-pyyaml.txt
#
# --only-binary=:all: allows no other package a source build in that
# invocation.
